Participants were allocated between the arms (Treatment, Control) in a 1:1 ratio using permuted-block randomization for the trial "Example trial". Randomization was stratified by site (North, South), giving 2 stratum list(s) of 40 allocations each, and a separate allocation sequence was generated for each stratum. Within each block the arms appeared in exactly the allocation ratio, in a randomly permuted order. Block sizes of 4, 6, 8 were drawn at random for each block, so that the block size -- and therefore the allocations remaining in a block -- could not be predicted from the allocations already revealed. The allocation list was generated before enrolment began with blockrandom 0.1.0 (open-source, MIT licence), using a seed held by the trial statistician; only the SHA-256 hash of the seed is recorded with the list (88c7bd18e04fa9108979f5501644f557433abbb28a337fe72943e7967f34caf5), so the list can be regenerated and verified from the seed without the seed travelling with it. The list used for enrolment (the sealed list) contains only the allocation identifier, stratum, sequence position and allocation, so the block structure cannot be inferred from it.
